# CoreMace

A PocketMine-MP plugin adding a craftable **MACE** and **Wind Charge** with custom combat/movement mechanics.

Originally built for the **VeoZax SMP** server as a private plugin. Since that legacy server has been shut down, this plugin is now open source.

## Features

- Craftable Mace
- Craftable Wind Charge
- Auto loads the plugin even there's no devtools support
- Crafting recipes work in any world.

## Requirements

- PocketMine-MP (legacy / old-API core, uses `pocketmine\level\*`)
- PHP 7.0+

## Installation

1. Download the latest `.phar` (or the source folder) from [Releases](../../releases).
2. Drop it into your server's `plugins/` folder.
3. Restart the server.
